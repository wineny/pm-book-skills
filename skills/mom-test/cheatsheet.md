# 치트시트 — 더 맘 테스트 (인터뷰 현장용 의사결정 가이드)

## 질문 판정 규칙
- 질문이 **내 아이디어**에 관한 것이면 → 상대의 **삶**에 관한 질문으로 바꿔라
- 질문이 **미래/가정**("~하시겠어요?")이면 → **과거의 구체적 사례**("마지막으로 언제?")로 바꿔라
- 숫자가 붙은 미래 질문("X만큼 내실래요?")도 똑같이 나쁘다 — 더 잘 속일 뿐
- 모든 대화에 **무서워서 떨리는 질문 1개** 이상. 예상 밖의 답이 와도 할 일이 안 바뀌면 그 질문은 버려라

## 대화 중 실시간 대응
| 들리는 것 | 정체 | 즉시 할 것 |
|---|---|---|
| "멋지네요/마음에 들어요" | 칭찬 | 흘려보내기: "요즘 이건 어떻게 처리하세요?" |
| "항상/보통/절대 ~해요" | 빈말(일반론) | 닻: "마지막으로 그게 언제였어요?" |
| "무조건 살 거예요" | 빈말(미래 약속) | 현재의 약속으로: LOI·선주문·소개 요청 |
| "엑셀 동기화 되나요?" | 기능 요청 | 파기: "그게 되면 뭘 할 수 있게 되나요?" |
| "그게 제 하루 최악이에요" | 강한 감정 | 무조건 파기: "왜 아직 못 고치셨어요?" |
| "출시되면 알려주세요" | 시간 끌기 | 오늘 가능한 약속 요청으로 전환 |
| "음, 잘 모르겠네요" | 미적지근 | 설득 금지. 무관심의 정체만 확인 후 감사 인사 |

## 문제의 진짜 크기 판별 (진통제 vs 비타민)
- "그게 어떤 영향을 미치나요?" → 파장 없음 = 비타민
- "다른 해결법을 검색해봤어요?" → 안 해봄 = 내 것도 안 산다
- "지금 해결에 얼마 쓰세요?" → 가격 기준점 (월 100파운드 땜질 vs 연 12만 파운드 대행사)
- 임계값: 대화 3~5건(좁은 세그먼트)이면 패턴이 보인다. 10건+에도 제각각 = 세그먼트가 너무 넓음

## 줌인 판단
- 돈 낼 문제임을 **100% 확신** → 곧장 줌인 ("마케팅에서 가장 큰 문제가?")
- 확신 없음 → 일반부터 ("요즘 가장 큰 목표/골칫거리가?") — 관심 있으면 알아서 꺼낸다

## 위험 유형별 대화의 한계
- 시장 위험 중심(원하나? 돈 내나?) → 대화로 검증 가능
- 제품 위험 중심(만들 수 있나? 키울 수 있나?) → 대화는 출발점만. 더 일찍, 더 적은 확신으로 만들기 시작
- 판별 tell: "당신이 ~만 해주면 돈 낼게요" = 부담이 제품으로 넘어온 것 (당연한 답, 검증 아님)

## 미팅 성패 판정
- 성공 = **사실 + 약속(시간/평판/돈) + 진전** 중 하나 이상을 들고 나옴
- 실패 = 칭찬 또는 미적지근한 말만 들고 나옴 → 원인: ①의견을 물었다 ②약속을 요청하지 않았다
- 거절 ≠ 실패 (강력한 부정 데이터). **묻지 않음 = 실패**
- 화폐 환산: 상대가 내놓는 것이 많을수록 신뢰도 ↑. 칭찬 비용 = 0 = 데이터 0

## 세그먼트 선택
- 좋은 세그먼트 = 누구-어디 짝. 어디서 찾을지 모르면 더 잘라라
- 선택 기준: ①수익성 ②접근성 ③보람
- 피드백이 뒤죽박죽 = 20명과 대화한 게 아니라 20가지 유형과 1번씩 대화한 것

## 프로세스 임계값
- 미팅 준비: 1시간까지 (그 이상 = 시간 끌기)
- 풀타임 대화 기간: 1~2주까지 (그 후 약속을 내밀어라)
- 미팅 인원: 2명 최적 (메모 담당 + 대화 담당), 3명 = 압도
- 고객 질문 하나에 답하는 기한: 1주일
- 배움의 외주: 금지 (반복 가능한 영업 프로세스 확보 전까지)

## 시늉 감지 (하나라도 지속되면 시간 낭비 중)
내가 더 말함 · 칭찬을 들음 · 다음 단계 모름 · 메모 없음 · 팀 복기 없음 · 예상 밖 답에도 아이디어 불변 · 무서운 질문 0개 · 답하려는 핵심 질문 불명

## 준비의 최소 단위
"이 사람들한테서 뭘 배우고 싶은가?" — 시간이 빠듯하면 이 질문 하나가 준비의 전부
