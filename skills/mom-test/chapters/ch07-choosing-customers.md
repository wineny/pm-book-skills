# 7장: 고객 선택하기 — 모두가 고객이면 아무도 아니다

## Core Idea
스타트업은 굶어 죽는 게 아니라 (선택지·잠재 고객·아이디어가 너무 많아서) 익사한다. 세그먼트가 넓으면 피드백이 사방으로 튀어 옳은지 그른지조차 증명할 수 없다. 고객 슬라이싱으로 '누구-어디 짝'이 나올 때까지 잘라내라.

## Frameworks Introduced
- **고객 슬라이싱 (Customer Slicing)**: 넓은 세그먼트에서 출발해 점점 구체적인 하위 집합으로 잘라내는 절차.
  - 1단계 — 인구통계와 동기 분리: "이 그룹 안에서 어떤 유형이 이걸 가장 원할까?" / "모두가 사거나 쓸까, 일부만?" / "왜 원할까(문제·목표)?" / "그 동기를 모두가 가졌나?" / "그 밖의 동기는?" / "이런 동기를 가진 다른 유형은?"
  - 2단계 — 행동과 장소: "목표를 이루거나 문제를 버티려고 지금 이미 무엇을 하고 있나?" / "이 인구통계 그룹은 어디서 찾나?" / "그 임시방편 행동을 하는 사람들은 어디서 찾나?"
  - 찾을 길이 없는 그룹이면 더 잘게 잘라라 — 연락이 닿지 않는 세그먼트는 쓸모없다.
- **시작 세그먼트 선정 3기준**: ①수익성이 좋은가 ②접근하기 쉬운가 ③그들 중심으로 사업을 일구는 게 보람 있는가. (고객과 오래 이야기하게 되니 함께 있기 즐거운 상대를 골라라. 세그먼트는 나중에 다시 넓힐 수 있다.)
- **넓은 세그먼트의 3가지 증상**: ①선택지에 압도되어 어디서 시작할지 모름 ②앞으로 못 나가면서 틀렸다는 증명도 못 함 ③뒤섞인 피드백을 해석 불가.

## Key Concepts
- **크게 시작한 회사는 없다**: 구글=박사 과정 학생의 코드 검색, 이베이=페즈 디스펜서 수집가, 에버노트=엄마들의 레시피 저장.
- **"학생" 함정**: 학생을 위한 제품 → 정식 인용 표기 / 연습 문제 / 아이패드 지원 / 컴퓨터 1대에 80명 / 오프라인 지원 요청이 쏟아짐. 알고 보니 박사 과정생, 입시생, 홈스쿨링 부모, 인도 시골 마을, 아프리카 불안정 통신 사용자 — 전부 "학생". **고객 20명과 대화한 게 아니라 서로 다른 20가지 유형과 한 번씩 대화한 것.**
- **엉뚱한 사람과 이야기하게 되는 3경로**: ①세그먼트가 너무 넓음 ②복수 세그먼트 중 일부를 놓침(아이 앱=아이+부모, 공립학교=교사·학생·행정실·학부모회·납세자) ③기업 구매 절차의 이해관계자 간과. 중요한 파트너에 기대는 사업이면 파트너의 목표·제약도 고객만큼 파악하라.

## Worked Example
**슈퍼푸드 조미료**: 보디빌더·식당·엄마들 모두가 쓸 수 있는 제품 — 그래서 제자리걸음(한쪽을 만족시키면 다른 쪽이 실망). 가장 살 것 같은 고객 = 건강식품점에서 장 보는 어린 자녀 둔 엄마들, 찾을 곳 = 바로 그 건강식품점. **작은 독립 건강식품점만 골라**(슬라이싱) 아침 식사 코너 옆 진열을 부탁(매대 한 칸 = 약속 요청으로 막연한 의견 차단) → 일주일 뒤 재방문 → 팔리면 매장 시식 행사로 최종 소비자와 대화.
**"학생의 말하기 불안" 슬라이싱**: 학생 → 첫 면접을 앞둔 긴장한 졸업 예정자(동기: 중요한 날 망치지 않기) → 같은 동기의 다른 인구통계: 방송 첫 출연자, 결혼식 축사자, 북 투어 신인 작가 → 추가 동기(평생 기술 연마, 비원어민 버릇 교정) → 교사·영업사원, 외국인 교환학생, 학회 발표 앞둔 비원어민 박사생. 구체적일수록 찾을 곳이 보인다: 비원어민 박사생=학과 지도교수, 신인 작가=아마존 출간 예정 목록+트위터, 축사 긴장자=구글 검색 광고, 최종 선택=토스트마스터스 모임(하룻저녁에 대화 10건+).

## Anti-patterns
- **"광고주" 세그먼트**: 저자의 실패담. 모두를 동시에 상대 → 모든 요청에 "네" → 어떤 기능 논쟁이든 "그 사람들이 좋아할걸"로 이김 → 옳은지 그른지 영영 증명 불가. 크리에이티브 에이전시로 좁힌 뒤에야 신호가 보임.
- **보고서용 인터뷰**: 가장 높은 사람이 아니라 고객을 대표하는 사람과 이야기하라. 저자는 정장 입은 사람들과만 대화하고 정작 제품을 쓸 십 대들과는 전혀 대화하지 않았다.

## Key Takeaways
1. 일관된 문제와 목표가 보이지 않는다면, 아직 충분히 구체적인 세그먼트가 아니다.
2. 좋은 세그먼트는 **누구-어디 짝**이다. 어디로 가야 할지 모르겠다면 알게 될 때까지 계속 잘라내라.
3. 여러 부류를 위한 그저 그런 제품과 한 부류를 위한 끝내주는 제품은 전혀 다른 이야기다.
4. 업계 전문가와 이야기하면 그 업계의 분류 체계를 얻어 출발점이 좋아진다.
5. 온종일 이론 짜지 마라 — 최적 고객에 빠르게 도달해 사업을 밀고 나가는 용도다.
