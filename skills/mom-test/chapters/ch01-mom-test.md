# 1장: 맘 테스트 — 엄마도 거짓말 못 하게 묻는 법

## Core Idea
"이 아이디어 괜찮아요?"는 누구에게도 물으면 안 되는 질문이다. 아이디어를 아예 꺼내지 않고 상대의 삶·과거의 구체적 사실을 물으면, 엄마조차 거짓말할 수 없는 데이터를 얻는다.

## Frameworks Introduced
- **맘 테스트 (The Mom Test)**: 좋은 질문을 만드는 3가지 규칙 (원문 그대로)
  1. 내 아이디어 대신 **상대의 삶**에 대해 이야기하라
  2. 미래에 대한 일반론이나 의견 대신 **과거의 구체적인 사실**을 물어라
  3. **말은 줄이고 더 많이 들어라**
  - When to use: 모든 초기 고객 대화. 제대로 하면 상대는 내게 아이디어가 있다는 것조차 눈치채지 못한다.
- **쓸모 있는 대화의 기준**: 고객의 삶과 세계관에 대한 **구체적인 사실**을 얻었는가 → 그 사실이 사업을 개선하는가.
- **문제-해결책 분업**: "문제는 그들의 것, 해결책은 여러분의 것." 고객은 내게 무엇을 만들지 말해줄 수 없고, 나는 고객에게 그들의 문제가 뭔지 말해줄 수 없다. 위원회식 제품 개발이 아니라, 정보를 모은 뒤 창업자가 비전의 도약을 하는 것.

## Key Concepts
- **거짓 긍정(false positive)**: 잘못된 대화가 주는 "옳은 길을 가고 있다"는 착각. 돈·시간·팀을 과잉 투자하게 만드는 최악의 결과물.
- **아이디어를 너무 일찍 꺼내는 실수**: 거의 모두가 저지르는 실수는 늦게 꺼내는 게 아니라 너무 일찍 꺼내는 쪽. 꺼내지 않기만 해도 질문의 질이 자연히 좋아진다.
- **목발 질문**: "제가 더 물어봤어야 하는 게 있을까요?" — 업계 초보일 때 상대가 질문 방향을 바로잡아주게 하는 임시 보조 장치.

## 좋은 질문 / 나쁜 질문 판정표
| 질문 | 판정 | 이유/고치는 법 |
|---|---|---|
| "이거 괜찮은 아이디어 같아요?" | 최악 | 아이디어의 좋고 나쁨은 시장만 안다. → 지금 그 일을 어떻게 하는지 보여달라 하라 |
| "X 제품 있으면 사시겠어요?" | 나쁨 | 미래 낙관 + 비위 맞추기 = 답이 거의 늘 "네" → 지금 X를 어떻게 해결하고 비용이 얼마인지 물어라 |
| "X에 얼마 내실 거예요?" | 나쁨 | 숫자가 붙어 더 잘 속인다 → 그 문제로 지금 얼마가 드는지/얼마를 내고 있는지 물어라 |
| "꿈의 제품 기능은?" | 조건부 | 후속 질문(왜 원하는지)이 있을 때만 좋다. 배구의 '토스' |
| "왜 굳이 그렇게까지 하세요?" | 좋음 | 드러난 문제 → 진짜 문제(동기)로 넘어가는 최고의 질문 |
| "그게 어떤 영향을 미치나요?" | 좋음 | '돈 내서라도 풀 문제' vs '감당되는 짜증'을 가름 + 가격 신호 |
| "마지막으로 그 일 있었던 때를 처음부터 끝까지" | 좋음 | 의견이 아닌 행동에서 배운다. 업무 흐름·도구·제약이 한 방에 나옴 |
| "그 밖에 또 뭘 시도해보셨어요?" | 좋음 | 해결책을 검색조차 안 해봤다면 내 것도 안 산다 |
| "지금은 그걸 어떻게 해결하세요?" | 좋음 | 업무 흐름 + 가격 기준점(월 100파운드짜리 땜질 vs 연 12만 파운드 대행사) |
| "그 돈은 어디서 나오나요?" | 좋음 | B2B 필수. 누구 예산인지, 누가 거래를 죽일 수 있는지 → 영업 로드맵 |
| "또 누구랑 이야기해보면 좋을까요?" | 좋음 | 모든 대화의 마무리. 소개가 소개를 낳는다 |

## Worked Example
아이패드용 디지털 요리책 아이디어를 두고 엄마와 나눈 두 대화:
- **실패 버전**: "엄마 아이패드 좋아하죠? 요리책 앱 있으면 살래요?" → 유도된 "응", 가정형 질문, 미적지근한 신호 무시, 기능 나열 → "정말 멋지구나"(영혼 없는 칭찬)를 검증으로 착각 → 퇴사·저축 투입 → 아무도(엄마조차) 안 삼.
- **통과 버전**: 아이디어를 한 번도 안 꺼냄. "새 아이패드 쓸 만해요?" → "마지막으로 거기서 한 게 뭐였어요?"(과거 사실) → "그거 앱으로 했어요?" → "책장의 새 요리책은 어디서 났어요?" → "직접 산 마지막 요리책은?" 결과: ①노인들은 평범한 레시피 모음을 안 원한다(선물로 받고 안 펼침) ②앱을 검색하지 않는 세그먼트라 신문 PR 같은 채널이 관건 ③틈새(비건) 요리책은 경험자도 산다 → 공략 가능한 세그먼트 2개 + 검증할 위험 요소 도출.

## Anti-patterns
- **의견 수집**: "의견은 아무 쓸모가 없습니다." VC조차 미래 예측은 틀릴 때가 더 많다.
- **미래형 질문에 기대기**: "미래가 걸린 답은 죄다 지나치게 낙관적인 거짓말입니다."

## Key Takeaways
1. 고객과의 대화는 기본값이 '엉망'이다. 바로잡는 건 내 몫.
2. 사람들은 내가 듣고 싶어 하는 말이다 싶으면 거짓말을 한다 — 질문에서 내 아이디어와 기대를 빼라.
3. 사람들은 자기 문제가 뭔지는 알지만 어떻게 풀지는 모른다. 기능 요청이 아니라 동기·제약을 수집하라.
4. 정확히 얼마 낼지는 안 말해줘도, 그게 자기에게 얼마짜리인지는 자주 보여준다.
5. 상대의 목표를 이해하기 전까지는 눈 감고 총 쏘는 셈이다.
