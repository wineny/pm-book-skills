# 2장: 나쁜 데이터 피하기 — 칭찬과 빈말에 속지 않기

## Core Idea
나쁜 데이터는 거짓 부정(멀쩡한 아이디어를 죽은 것으로 착각)과 더 위험한 거짓 긍정(틀렸는데 맞았다고 확신)을 만든다. 나쁜 데이터 3종 — 칭찬, 빈말, 아이디어 — 은 각각 흘려보내고, 닻 내리고, 밑을 파는 것으로 대처한다.

## Frameworks Introduced
- **나쁜 데이터 3종 (Bad Data)**:
  1. **칭찬** — 흘려보내라(deflect)
  2. **빈말(fluff)** — 일반론("항상/보통/절대")·미래 약속("~할 거예요")·가정형 추측("~할지도") — 닻을 내려라(anchor)
  3. **아이디어**(기능 요청) — 밑을 파고들어라(dig)
- **빈말에 닻 내리기**: 일반론이 나오면 "마지막으로 그게 언제였어요?" → 과거의 구체적 사례로 고정 → 그때 이야기를 듣는다. 빈말 유발 질문("혹시 ~하실 의향?")은 그 자체가 해롭진 않고 답을 믿는 게 잘못 — 구체 질문으로 넘어가는 토스로 쓸 수 있다.
- **파토스 문제 (The Pathos Problem)**: 무심결에 인정을 구하며 자존심을 드러내면, 상대가 듣기 좋은 말로 나를 보호해줘야 한다고 느끼게 되는 것. 대처: 대화를 상대에게 집중시키고 구체적 사례를 물어라 — 사람들은 이미 일어난 구체적인 일에 대해서는 좀처럼 거짓말하지 않는다.

## Key Concepts
- **세상에서 가장 치명적인 빈말**: "그거라면 무조건 살 거예요." — 저자의 첫 직장 스타트업은 이 말을 약속으로 착각해 약 1,000만 달러를 날렸다.
- **불평꾼 ≠ 고객**: "누가 X 좀 만들어야 한다니까!" → "찾아보셨어요?" → "아니요" = 그 사람은 고객이 아니다. 그걸 알게 된 것 자체가 수확.
- **칭찬 낚시**: 이미 마음을 정해놓고 축복만 구하는 것 ("이 아이디어 마음에 들어요?").
- **자기 자랑(pitching)**: 인정 구하기의 어두운 뒷면 — 상대를 인질로 잡고 칭찬을 강요. 빠졌다면 사과하고 돌아오라: "앗, 제가 자랑 모드로 들어갔네요. 방금 하시던 얘기로 돌아가도 될까요?"

## 파고들기 질문 세트
- 기능 요청에: "그걸 왜 원하세요?" / "그게 되면 뭘 할 수 있게 되나요?" / "그게 없는 지금은 어떻게 버티세요?" / "출시를 미뤄야 할 기능인가요, 나중에 넣어도 되나요?" / "일상에 어떻게 들어맞을까요?"
- 감정 신호에: "그 얘기 좀 더 들려주세요." / "뭐가 그렇게 끔찍하던가요?" / "왜 아직 못 고치셨어요?" / "꽤 들떠 보이시는데, 큰 건인가 봐요?" / "계속해보세요."
- 강한 감정(분노·민망함·환희)은 무엇이든 팔 가치가 있다.

## Worked Example
**MTV 분석 대시보드 사건 (저자 첫 회사 Habit)**: MTV가 "캠페인 분석·리포트가 필요하다"고 요청 → 요청을 곧이곧대로 받아 화려한 셀프서비스 대시보드를 맞춤 제작 → 그런데 매주 금요일마다 전화로 "리포트 뽑아서 이메일로 보내달라"는 요청이 계속됨 → 나중에 로고 넣은 리포트를 요청하기에 "이 기능을 왜 원하세요? 데이터는 똑같잖아요?"라고 묻자 → "사실 이거 아무도 안 읽어요. 저희 고객들이 매주 뭔가 이메일로 받는 걸 좋아해서, 그럴싸하면 더 만족할 것 같아서요." 그들은 분석을 요청했지만 진짜 원한 건 **자기네 고객을 만족시킬 방법**이었다. 동기를 알았다면 대시보드 대신 스케줄러 하나(혹은 인턴의 수작업)로 충분했다 — 만든 것의 90%가 헛수고, 3개월 손실.

## Anti-patterns
- **칭찬을 데이터로 기록**: "그 미팅 진짜 잘됐어" / "다들 좋아해요" = 경고 신호. 왜 좋아했는지·얼마를 아끼는지·일상에 어떻게 들어맞는지 답 못 하면 데이터가 아니라 칭찬을 쥔 것.
- **기능 요청을 할 일 목록에 직행**: 기능 과잉(feature creep)으로 가는 고속도로. 받아 적되 동기를 파라.
- **상대 말 끊고 바로잡기**: 상대가 머릿속 세계관을 열어 보이려는 순간을 죽인다. 보충 설명은 나중에 얼마든지.

## Key Takeaways
1. 칭찬은 "고객 학습의 바보의 금" — 반짝이고, 정신을 흐트러뜨리고, 완전히 쓸모없다.
2. 좋은 대화는 듣고 싶은 말로 끝날 필요가 없다 — 진실에 다다르면 된다. "저희한텐 큰일 아니에요"도 성공적인 배움.
3. 아이디어와 기능 요청은 **이해하되, 따르지는 마라**.
4. 일단 아이디어를 입에 올리면 사람들은 내 기분을 지켜주려 든다.
5. 말을 많이 할수록, 더 못하고 있는 것이다.
