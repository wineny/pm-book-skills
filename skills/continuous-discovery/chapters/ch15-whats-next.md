# 15장: 다음은 무엇인가 — 후속 학습 자원

## Core Idea
책의 끝이 여정의 끝일 필요는 없다. 읽은 것을 실무로 옮기기가 어렵다는 전제 아래, 저자가 계속 연습할 경로를 안내하며 마무리하는 장이다.

## Key Concepts
- **의도적 반복 연습(deliberate practice)**: 심화 강좌의 설계 원리. 스킬 하나를 반복해 몸에 붙이는 방식.
- **스토리 기반 인터뷰(story-based interviewing)**: '지속적 인터뷰' 강좌가 다듬는 역량.
- **기회 매핑**: 기회 공간을 단계별로 구조화하는 작업.

## Mental Models
- **책을 다 읽은 시점을 도착점이 아니라 연습의 출발점으로 생각하라.**

## Key Takeaways
1. 읽기만으로는 실무로 안 넘어간다. 별도의 연습 장치를 붙여라.
2. 습관 하나를 골라 의도적 반복 연습 대상으로 삼아라.
3. 혼자 하지 말고 같은 것에 투자하는 동료 집단 안에서 하라.
